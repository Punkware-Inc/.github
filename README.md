## `> WHO WE ARE`

**Punkware Inc.** is an independent development organization built around experimentation, creativity, and technical freedom.

We explore ideas, build software, break assumptions, and challenge conventional approaches to development.

We believe technology should be shaped by curiosity, not conformity.

No corporate theater. No unnecessary complexity. No innovation by committee.

Just ideas, code, and the freedom to create.

## `> OUR PHILOSOPHY`

> **"Good software solves problems. Great software questions why those problems exist."**

We don't believe every project needs to become a product.

Some projects exist to solve problems.  
Some exist to explore possibilities.  
Some exist simply because building them is interesting.

**Experimentation is not a waste of time. It's where innovation begins.**

## `> THE WORKSHOP`

Our repositories represent different stages of development, experimentation, and exploration.

| Classification | Description |
|:---|:---|
| `STABLE` | Projects intended for regular use |
| `ACTIVE` | Currently evolving projects |
| `EXPERIMENTAL` | Concepts, prototypes, and technical experiments |
| `ARCHIVED` | Preserved projects and development history |

Explore our work:

**[→ Browse all repositories](https://github.com/orgs/Punkware-Inc/repositories)**

## `> OPEN SOURCE & CONTRIBUTIONS`

We appreciate curiosity, constructive criticism, and meaningful contributions.

If a repository accepts contributions, check its documentation and contribution guidelines before submitting changes.

Not every experiment is production-ready, and not every repository is intended for public collaboration.

Respect project licenses and responsible disclosure practices.
